# キャンペーン参加者集計ツール
実務で活用していたものをPythonでリファクタリングしたものになります。(実務ではExcel VBAを使用)　自社独自のキャンペーンとして○○円以上○○円未満の投資を行った方にXX円付与するというものを行っておりました。Excelファイルに仮のデータを格納しております。そのデータをもとに付与額を出力できます。同じ人が複数回投資を行ったり、申し込みの取消にも対応しております。※複数回の場合はそれらの合計で付与額判断しています。
Excelファイルに仕様書を添付しております。

## 動かし方
pip install pandas openpyxl
python キャンペーン集計.py
